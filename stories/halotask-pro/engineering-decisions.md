# Engineering Decisions: Selected Source Milestones

This file is a supporting chronology for the book, not a complete commit-by-commit history. Dates and descriptions come from the public repository's commit metadata and its checked-in engineering log. These are documented milestones; the exact causal story behind each decision is only stated where source comments or logs support it.

| Date | Decision or change | Why it matters to the book |
|---|---|---|

## Important verification boundary

The chronology is grounded in source commit metadata and checked-in engineering notes. It does not assert that all features were complete on those dates, that tests passed on the listed commits, or that deployments were healthy. Some milestone descriptions are taken from the project's own engineering log and should be read as recorded project history, not as independent production validation.
