# DevLens: A Diagnostics Engine Where Capture and Presentation Stay Separate

DevLens is a framework-agnostic, embeddable diagnostics engine that brings runtime errors, console activity, network outcomes, and React component errors into one normalized event pipeline.

The detailed, chapter-based engineering book now lives in [the DevLens storybook](devlens/README.md). It covers the event model, EventBus and EventStore boundaries, plugin lifecycle, network capture and URL redaction, the isolated Panel, inspection workflows, session import, React integration, testing, and architectural decisions.
